# Convolutional Neural Network (CNN) Implementation

This project demonstrates how to build and train a Convolutional Neural Network (CNN) from scratch using Jupyter Notebook and to classify handwritten digits from the MNIST dataset. 

### Features

- Implemented with PyTorch

- Includes:

    - Data loading and transformation

    - CNN model architecture definition

    - Training and evaluation loop

    - Accuracy tracking across epochs
 
### Results

- The model achieves improving accuracy over training epochs.

- Provides training and validation accuracy visualizations.
